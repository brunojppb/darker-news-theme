# Privacy policy

Dark theme for Hackernews collects no data.

- The extension runs only on pages at `https://news.ycombinator.com/`.
- It is one stylesheet and four font files. It runs no scripts.
- It sends nothing to any server. The fonts ship in the extension, so the theme makes no network requests.
- It stores nothing. It uses no cookies, no `chrome.storage`, and no browser storage.
- It asks Chrome for no permissions.

The source code is public: https://github.com/brunojppb/darker-news-theme

Questions go to the issue tracker: https://github.com/brunojppb/darker-news-theme/issues
